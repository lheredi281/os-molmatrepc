GUIA RAPIDA DE OPERACION - TABLERO FIBA (MODO TECLADO PC)
============================================================

Este documento es una guía rápida para el árbitro o el operador de la mesa de control. 
Actualmente el sistema está configurado para ser operado temporalmente mediante el teclado de la computadora, hasta que se conecte la consola física (Mando ESP32).

------------------------------------------------------------
1. CONTROL DEL RELOJ DE JUEGO Y PERIODOS
------------------------------------------------------------
- [ BARRA ESPACIADORA ] -> INICIAR / DETENER EL RELOJ.
- [ CLIC IZQUIERDO ] SOBRE EL RELOJ -> Se abrirá una ventana donde podrás escribir el tiempo exacto que desees (ej: escribe "4" para poner el reloj en 4:00, o "0.5" para 30 segundos).
- [ CLIC IZQUIERDO ] SOBRE EL "PERIODO" (El número 1 amarillo) -> Avanzará al siguiente periodo. Al hacerlo, el sistema reseteará automáticamente las faltas de equipo y reiniciará el reloj a 12:00.

------------------------------------------------------------
2. EQUIPO LOCAL (Columna Izquierda)
------------------------------------------------------------
[ Q ] -> Sumar 1 punto (Tiro Libre)
[ W ] -> Sumar 2 puntos (Doble)
[ E ] -> Sumar 3 puntos (Triple)

[ A ] -> Sumar Falta de Equipo
*(El sistema calculará automáticamente si el equipo entra en situación de BONUS al llegar a la 5ta falta)*


------------------------------------------------------------
3. EQUIPO VISITANTE (Columna Derecha)
------------------------------------------------------------
[ P ] -> Sumar 1 punto (Tiro Libre)
[ O ] -> Sumar 2 puntos (Doble)
[ I ] -> Sumar 3 puntos (Triple)

[ L ] -> Sumar Falta de Equipo


------------------------------------------------------------
4. CONTROL DE JUGADORES (Con el Mouse)
------------------------------------------------------------
Dado que por ahora se opera desde la PC, la forma más rápida de controlar las faltas de los jugadores es usando el ratón:

- [ CLIC IZQUIERDO ] sobre el nombre/dorsal de un jugador: Suma 1 Falta Personal a ese jugador. (¡El sistema también le sumará la falta al equipo automáticamente!).
- [ CLIC DERECHO ] sobre un jugador: Lo marca como "En Cancha" (enciende el LED verde) o lo manda al banco (apaga el LED).

Nota: Si un jugador llega a la 5ta falta, el sistema encenderá el LED rojo, el fondo se pondrá oscuro y el jugador será automáticamente retirado de la cancha.
