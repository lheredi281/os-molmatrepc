# 🏀 Kiosco Montmartre - Tablero Anotador FIBA

Sistema integral para visualización de Tablero Anotador Profesional y Publicidad Dinámica.

---

## 🚀 Instalación Desatendida (Para nuevas PCs/TVs)

Para instalar todo el sistema de forma automática en una Netbook o PC con **Debian 12 (64-bits)** recién instalado, abre la terminal, inicia sesión como `root` (escribiendo `su -`) y ejecuta este único comando:

```bash
curl -sSL anotadormontmartre.electronicat-lab.com | bash
```

### ¿Qué hace este instalador?
1. Descarga todas las dependencias necesarias de Linux.
2. Instala el entorno gráfico ligero (Openbox).
3. Instala Node.js v20.
4. Descarga este repositorio.
5. Configura el encendido automático de pantalla completa.
6. Habilita el actualizador silencioso en segundo plano.
